# Contributing

Thanks for helping improve Minecraft: D Edition.

## Before opening an issue

- Search existing issues first.
- Use the latest Test release when reproducing a bug.
- Include the operating system, renderer, game version, reproduction steps,
  expected result, and actual result.
- Remove account tokens, EOS credentials, private invitation codes, usernames,
  and world data you do not want to publish.

## Pull requests

Keep changes focused and explain the player-visible result. Run the relevant
smoke tests described in `README.md` and include the results in the pull request.
Do not commit generated builds, locally imported Minecraft assets, Epic Online
Services SDK files, credentials, save files, or logs.

This repository does not yet publish an open-source license. Opening an issue
or pull request does not grant permission to redistribute the project or its
third-party assets.
