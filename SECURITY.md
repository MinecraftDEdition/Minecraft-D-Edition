# Security policy

## Reporting a vulnerability

Do not publish credentials, authentication tokens, private EOS invitation
codes, or an exploitable security report in a public issue.

For now, report security-sensitive problems through a private GitHub security
advisory for this repository. For ordinary gameplay bugs, use the public issue
tracker.

Include the affected version and platform, a concise reproduction, the impact,
and any logs with private information removed. Please allow time for the issue
to be reproduced and fixed before disclosing it publicly.
